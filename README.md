<div>
  <h3>About me</h3>
  <div><img align="right" alt="GIF" src="https://raw.githubusercontent.com/Andrew-Velox/Andrew-Velox/main/.github/assets/samurai4.png" width="200" height="100%" /></div>

  I write code mostly in **Swift** and **Python**. I also do iOS security and reverse engineering research. Nothing I've built is massive, but I try to actually finish things — turns out that's the hard part.

  ### Things I've made
  * **[durak-solver](https://github.com/gerdaroot/durak-solver)** — *Swift*
    A solver for Durak, the card game. I got tired of losing to my friends, so I wrote something that plays better than I do. It mostly works.
  * **[PancakeStore](https://github.com/gerdaroot/PancakeStore)** — *Swift, iOS*
    Contributed the first Russian localization for this open-source iOS application, which was successfully reviewed and accepted by the developers.
  * **[apiservice](https://github.com/gerdaroot/apiservice)** — *Python, FastAPI*
    Built this to learn how a backend is supposed to be structured instead of guessing. Still refactoring it.

  ### What I'm doing now
  Reading other people's code more than writing my own. Slower, but I learn more that way.
  Also learning Japanese. Currently at the stage where I can read hiragana — just very slowly, and understand roughly none of it. Open to freelance and open source work.
